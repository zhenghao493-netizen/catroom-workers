# UI 051 — mobile compact flight layout

Presentation patch on release 0.5.0 / ruleset flight-lab-1. No server, engine,
board drawing, piece animation, networking, storage or Wrangler changes.

- 44px player strips; two rows for 3–4 players.
- Reserved two-row operation panel: die/status + main action, then four 44px choices.
- Board fits the remaining viewport height without being covered by a floating toolbar.
- Theme, chat, rules, room actions and recent moves are accessible from More on mobile.
- Original controls are moved, not cloned: chat drafts/listeners survive rotation.
- Finished-round host button opens an explicit rematch confirmation, using existing reset.
  No automatic reset; visitors wait for the host.
- HTML includes `meta[name=catroom-ui]` = `compact-1`; API version remains 0.5.0.

## Validation performed

`python release-tests/compact-layout.py`: 344 local Chromium assertions passed.
Nine viewport sizes (320×568 through 430×760 plus 390×844 and 844×390), 2/3/4
players, long names, roll/choose/opponent/finished views, three themes, selection,
server-confirmed animation, pending lock, chat drafts and escaping, short chat
viewport, menu/rules dialogs, desktop restoration and disconnect states.
The network uses a test transport; no production game commands were sent.
35 tests of the unchanged production engine also passed in this work session.

At 390×700 CSS pixels (2 players): player strip 72→44px; operation area 297→120px;
board content 348→356px; main button bottom 878.5→627px, choices bottom 824.5→681px.
The complete board and both operation rows are within the viewport.

Real browser address bars, software keyboards, OS text scaling and phone hardware
still need field acceptance. Viewports below 520px portrait / 340px landscape retain
scrolling rather than crush controls. Existing rooms do not require a rules migration.
